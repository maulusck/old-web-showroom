README.TXT — please read before first boot

This disk holds one program group and nothing you did not ask for. * To open an item, point at its icon and double-click. On a touchscreen a single tap will do — we moved with the times, the icons did not. * File Manager shows the whole C: drive as a tree of yellow folders. Nothing is hidden. Nothing phones home. 437 KB free is still 437 KB free tomorrow. * Control Panel changes the colours, the cursor blink, and very little else. That was the point. A desktop you can hold in your head beats one you have to search. * Print Manager queues jobs to the dot-matrix down the hall. Listen for it. That sound is progress. Everything you see is grey on teal because grey on teal never went out of style — it simply waited. Close this window from the File menu above to return to Program Manager. -- The desktop, 1993 and still running
